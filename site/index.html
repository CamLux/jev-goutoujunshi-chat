Jev 聊天助手是什么？

Jev 聊天助手（Jev Chat Assistant）是开源的 AI 聊天辅助工具，提供 Android、Windows 和 macOS 版本。它帮助你分析消息、理解意图并起草候选回复，发送前由你检查和决定。

适合什么需求
需要斟酌措辞、理解对话语气或获得回复思路的个人用户；判断结果仅供参考。
平台与功能范围
三端独立维护。本页的无障碍读屏、ML Kit OCR、权限设置和聊天 App 兼容性说明以 Android 版为准；桌面端功能以各自项目说明为准。
费用与使用条件
Android 项目采用 MIT 许可，软件免费开源；模型接口使用你自己的 API Key，可能产生服务商费用。桌面端许可与要求见对应项目。

项目发布者：Finderchangchang。安装包、各平台说明与更新请查看 GitHub 项目主页。

    危险等级

  7. 是非

接下来：看它怎么工作

02怎么工作

从屏幕上的一条消息，到输入框里的一句话

中间只有这几步。实心的在你手机上完成，虚线的发往你自己配置的接口。

在你手机上发往你配置的接口

  1. 1

    采集屏幕消息

    无障碍服务读当前对话；读不到就截屏，用离线 OCR 认字

  2. 2

    Jev 判断

    意图 · 危险等级 0–9 · 该不该马上回

  3. 3

    生成模型起草

    3 条口语化候选：稳妥接话、给出行动或承诺、简短表态各一条；默认经 OpenRouter 调用 DeepSeek

  4. 4

    Jev 排序

    按合适程度重排，标出概率

  5. 5

    悬浮窗展示

    判断结论 + 三条候选，就在对话旁边

  6. 6

    复制 / 填入

    不发送，发送那一下由你按

知识库与关联上下文

本地维护笔记和联系人档案（关系、别名、备注）。笔记分两种：常驻的每次都带，其余按标签或标题匹配当前对话自动命中；开启历史后再带上这个人近期的聊天。回复口径与知识库一致，不编造知识库外的内容。联系人可跨 App 关联。

读不到就 OCR

控件树里没有正文时自动截屏，用 ML Kit 中文离线识别，不上传图片、不需要 Google 服务。任何 App 都能在悬浮窗菜单里手动「截屏识别一次」。

接口全可配

判断 / 回复 / 视觉三路接口的地址、密钥、模型分别可填。内置 OpenRouter、博查 Jev、TypeSafe 直连、DeepSeek 官方、通义兼容预设，各自一键连通测试。只填一把 OpenRouter 密钥就能用。

一套内核，多平台

判断、候选、排序、填入都在同一个内核里。新增一个 App 只需要实现一个几十行的适配器，其余全部复用。

03数据去向

它读你的聊天，所以先把话说清楚

这不是一个「什么都不收集」的产品：聊天文字确实会发给一个模型接口，只是那个地址由你自己填。除此之外的数据都留在你手机里。

你的手机

  • 读屏幕上正在显示的对话
  • 截图只在本机 OCR，不上传
  • 密钥、知识库、历史（默认关）只存本机

只在分析那一刻

当前对话的近 10 条消息 + 你填的关系描述；开了知识库、历史，才带上命中的笔记和这个人的历史

你配置的模型接口

OpenRouter · 博查 Jev · TypeSafe · DeepSeek · 通义 · 任意 OpenAI 兼容地址

作者的服务器

没有这一环：作者不架设服务器、不经手

读了什么
只读屏幕上正在显示的对话，用的是系统无障碍服务。不改任何 App 的安装包，不走它们的接口或账号，不读数据库。可以设会话白名单，也可以关掉自动分析，只在你点的时候读。
发给谁
只在判断那一刻，发给你自己配置的接口。作者不架设服务器、不经手。服务商拿到内容后怎么处理，以它们自己的隐私政策为准。
存在哪
密钥只存在 App 私有空间。聊天内容发完不落盘、不进日志。历史记录默认关闭，开了也只存本机。OCR 走 ML Kit 中文离线识别，图片不上传。
怎么删
设置页「清空知识库与历史」一键删除；卸载应用会连同密钥、设置一起清空，没有云端备份。
从不做什么
从不自动发送；不碰转账、红包、收款；无广告、无第三方统计 SDK。
读完整隐私政策

每一条都可以在 GitHub 仓库里对照源码核实。

06常见问题

装之前，你可能想问

会不会自动帮我发送？

不会。程序只把回复填进输入框，从不自动发送，也不碰转账、红包、收款。发不发、怎么改，都是你自己决定。

我的聊天内容会被上传吗？

只在判断那一刻，把屏幕上近几条消息、你填的关系描述发给你自己配置的接口（开了知识库还会带上命中的笔记和联系人备注，开了历史还会带上这个人近期的聊天），之后不落盘、不进日志，作者不架设服务器、不经手。密钥只存在 App 私有空间。历史记录默认关闭，开了也只存在本机。OCR 走的是 ML Kit 中文离线识别，图片不上传。完整隐私政策

要准备什么密钥？

一把 OpenRouter API Key 就能跑起来：填在「判断接口」，回复和视觉接口留空会自动继承。也可以三路分开配，内置 OpenRouter、博查 Jev、TypeSafe 直连、DeepSeek 官方、通义兼容预设，各自一键测连通。判断接口选「博查 Jev」的话，当前限时免费，key 在 jev.bocha.cn 领。

要花钱吗？

软件本身免费开源。模型调用走你自己的 API Key，按用量在对应服务商那边结算，项目不经手任何费用。

需要 root 吗？

不需要 root，也不用装任何模块。它是非侵入的：只读屏幕上正在显示的对话，不改任何 App 的安装包，不走它们的接口或账号。

支持 iOS 和电脑吗？

暂不支持 iOS。Android、Windows、macOS 的获取入口都在GitHub 项目主页；各平台独立维护。网页端还在规划中，目前没有网页版。

悬浮球不见了，或者读不到消息？

多半是国产 ROM 把后台冻结了。确认无障碍、悬浮窗、自启动、省电无限制四项都开着，小米 / HyperOS 尤其要开后两项；重装后悬浮窗权限会被重置，按主页向导再开一次。在聊天界面里随便点一下，通常就能恢复。

升级之后没反应？

把系统设置里的无障碍开关关掉再打开一次。1.3 起新增了截屏能力，服务需要重新绑定才会生效。

没找到答案？提一个 Issue，或到项目主页查看交流方式。

现在还做不到的

先说清楚，免得装完失望。

  • Jev 主要用英文训练，中文场景的判断质量会波动；题目是按亲密关系里的冲突场景校准的，群聊、工作聊天这类场景准确度会下降。
  • 群聊目前按一对一的方式分析，多人交叉对话时判断会不准。
  • 判断给出的是概率，不是确定结论，仅供参考。
  • 部分国产 ROM 的后台冻结策略可能让悬浮气泡短暂消失，开自启动和省电无限制可缓解。
  • X / Twitter 只在中文界面下验证过。
  • OCR 只认屏幕上看得见的部分，长消息被截断的地方读不到，偶尔有错字。
  • 知识库按标签或标题匹配，不做语义检索，笔记要打好标签才能被命中。
  • 安装包约 25 MB（含离线中文识别模型），只支持 arm64 机型。
