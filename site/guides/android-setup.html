使用指南

Jev 聊天助手安装与设置：从选择平台到第一条候选回复

先确认设备，再配置模型接口与读屏权限。本文说明 Android 的设置顺序、桌面版入口、费用和聊天数据去向。

Finderchangchang · 2026-09-30

先选平台，再照对应说明操作

Jev 的项目主页汇总 Android、Windows、macOS 三个独立维护的版本。下面的无障碍、悬浮窗和 OCR 步骤针对 Android；电脑端请从项目主页进入相应项目，按那里的说明配置。

平台官网当前列出的要求下一步
AndroidAndroid 11+，ARM64按下文安装和设置
WindowsWindows 10 1903+ / 11在主仓库选择 Windows 项目
macOSmacOS 13+，Apple Silicon在主仓库选择 macOS 项目

当前没有 iOS 版或可直接使用的网页版。获取入口统一在 GitHub 项目主页，具体兼容性以各端发布说明为准。

1. 获取并安装 Android 包

打开主仓库的「开始使用 Jev」，选择 Android 安装包。先核对系统版本与芯片架构；ARM64 之外的设备不在本页所述支持范围。

如果此前装过 debug 包，可能因签名不同无法覆盖安装。卸载会清除密钥和设置，操作前先确认需要保留的信息。普通版本升级后，可把系统无障碍开关关闭再打开，使服务重新绑定。

2. 配置模型接口，并测连通

打开 App 的「设置 → 接口」，可以看到判断、回复、视觉三张接口卡。按当前 README，起步可在判断接口填入自己的 OpenRouter API Key，其余两张留空继承配置；也可以为各路单独选择接口和模型。

  1. 确认服务商地址、模型与密钥相互匹配。
  2. 用接口卡上的连通测试检查配置。
  3. 连通后再回到聊天场景，排查读屏和权限。

软件开源免费不等于模型请求免费。费用由你选择的接口服务商按其规则收取。不要把 API Key 写进截图、Issue 或公开文档。

3. 按 App 向导开启必要权限

  • 无障碍：读取当前支持的聊天界面。
  • 悬浮窗：在聊天旁显示分析和候选回复。
  • 自启动与省电设置：部分系统会冻结后台，需按系统和 App 指引设置；小米 / HyperOS 尤其要检查这一项。

重装后，悬浮窗权限可能需要重新开启。权限设置只决定能否读取和显示内容，不会替代模型接口配置。

4. 用一段非敏感对话检查完整流程

在当前兼容列表支持的聊天场景中，先用不含敏感信息的内容试用：确认识别文字与屏幕一致，查看判断与候选，再选择复制或填入。检查措辞后由自己点击发送。

官网当前记录了 QQ、X 私信的验证情况，以及飞书通过 OCR 补正文的情况；它们不代表任意 App 版本和任意语言界面都已验证。请先查看官网兼容性说明。

遇到问题，按出现的位置检查

  • 接口连通失败：先检查接口地址、模型名、密钥和服务商状态。
  • 有悬浮球但没有文字：检查无障碍、聊天界面和兼容范围；OCR 只能读取屏幕上可见的文字。
  • 悬浮球消失：检查后台、自启动与省电设置，重装后重新检查悬浮窗权限。
  • 读到文字但建议不合适：先核对 OCR 和上下文，再调整候选。模型判断不是确定结论。

使用前理解数据会发给谁

Android 的截图识别在本机完成；触发分析时，聊天文字和你启用的背景信息会发给你配置的模型接口。离线 OCR 不代表整个分析过程离线。服务商如何处理请求内容，应查看其政策及 Jev 的隐私政策。

本文是按已公开项目资料整理的操作指南，不是对所有设备的独立实测报告。来源：项目 README及官网兼容说明。
